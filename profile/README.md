# Talarurus

Talarurus is an independent software studio building security, developer, and local-first software.

## Software and projects

- **[Hammerhead](https://github.com/talarurus/hammerhead)** — a local-first command-line tool for auditing source repositories without running their build scripts. Public development source is available on `v0.2-dev`; v0.2 is not released. The [company product page](https://talarurus.com/hammerhead/) documents the historical v0.1.0 release.
- **[plainbalance](https://github.com/talarurus/plainbalance)** — local-first personal finance software. The source is available as a v0.3.1 Developer Preview for fictional data; there is no verified consumer download.
- **[talarurus.com](https://github.com/talarurus/talarurus.com)** — the official company website.
